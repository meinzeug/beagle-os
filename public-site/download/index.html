Artifacts for host setup and endpoint rollout

Use this page as an operator reference, not as a one-click promise. Always verify checksums, keep release evidence, and treat clean-install validation as mandatory before broad rollout.

Latest GitHub release Release policy

Artifact groups

Beagle OS distinguishes host bootstrap artifacts from endpoint media artifacts.

HOST

Host installer artifacts

Use server installimage and installer outputs to bootstrap a clean Beagle host environment.

  • Clean-install focused
  • Used for release-gate validation
  • Must pass post-install health checks
EP

Endpoint media artifacts

Use endpoint images and USB payloads for thin-client runtime tests and assignment workflows.

  • VM-specific media recommended
  • Supports live and installer paths
  • Use reproducible writer scripts
META

Metadata and checksums

Every rollout should include checksum verification and release metadata capture for traceability.

  • Record artifact hashes
  • Keep release notes reference
  • Store validation evidence

Operator rollout flow

Recommended sequence for hobby labs and serious validations.

  1. Download current artifacts from GitHub releases or your mirrored host location.
  2. Verify checksums before writing media or starting installation.
  3. Install one clean host and run host health checks.
  4. Create VM, generate VM-specific endpoint media, and boot one endpoint.
  5. Validate first stream and document evidence before scaling rollout.

Checksum commands

sha256sum beagle-os-server-installer-amd64.iso
sha256sum beagle-os-server-installimage-amd64.tar.gz
sha256sum beagle-os-endpoint-live-amd64.iso

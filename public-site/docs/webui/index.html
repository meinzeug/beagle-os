WebUI Operator Guide

Operate host, VM, endpoint and stream lifecycle

The WebUI is the control surface for day-two operations on a standalone Beagle host. This guide is organized by operator workflow instead of legacy product-era sections.

Workflow 1: Initial host validation

  1. Login and complete onboarding for a fresh host.
  2. Open health checks and resolve all required red states.
  3. Confirm update channel and artifact metadata status.
  4. Review audit panel for startup anomalies.

Workflow 2: VM provisioning and lifecycle

  1. Open provisioning and create a VM with validated node and bridge values.
  2. Follow provisioning phases until guest readiness is green.
  3. Run lifecycle smoke: start, stop, restart and state persistence.
  4. Confirm VM appears in audit and event streams.

Workflow 3: Endpoint media and assignment

  1. Generate VM-specific endpoint media from Downloads.
  2. Boot endpoint and verify enrollment in Endpoints view.
  3. Check assignment, heartbeat and policy readiness.
  4. Use USB tab for controlled device passthrough actions.

Workflow 4: Stream operations

  • Verify target VM stream service health.
  • Confirm endpoint tunnel and network readiness.
  • Track session allocation and reconnect behavior in Streams view.
  • Escalate with captured logs and timestamps when sessions fail.

Workflow 5: Updates, backup and recovery

  • Apply rolling updates only for controlled validation.
  • Use stable channel for release-bound evidence runs.
  • Run backups before high-impact host or VM changes.
  • Test restore path on non-production VM before claiming backup readiness.

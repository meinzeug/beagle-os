Security Model
USB Passthrough

Secure by tunnel, not by exposed device ports

Beagle forwards endpoint USB devices through authenticated reverse tunnels. Device mapping remains tied to endpoint identity and assigned VM, with attach-detach actions visible in audit trails.

Flow overview

1. Endpoint export

Endpoint runtime exposes selected USB devices to local bridge services.

2. Reverse tunnel

Authenticated reverse tunnel from endpoint to host is established.

3. Host broker

Control plane validates VM assignment and tunnel ownership.

4. VM attach

Attach action maps selected device into assigned VM and records audit event.

Attach and detach operations

  1. Verify endpoint and VM assignment in WebUI.
  2. Open VM USB tab and select device from discovered endpoint list.
  3. Attach device and confirm device state in guest OS.
  4. Detach when finished and verify endpoint cleanup.

Keep attach-detach operations explicit. Do not leave long-running device mappings without operational need.

Supported device classes

  • Webcams and capture devices
  • Storage devices and removable media
  • Input devices requiring direct guest ownership
  • Security keys when policy allows passthrough

Security controls

  • Per-VM or scoped tunnel key material.
  • Strict ownership and permissions on authorized key files.
  • No public usbip listeners exposed on endpoint networks.
  • Audit events for attach, detach and rejection decisions.

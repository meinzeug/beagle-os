Getting Started

From clean host to first stream

This path is designed for production-like validation. Follow it in order and keep evidence for each gate: clean install, host health, VM lifecycle, endpoint enrollment and stream success.

Prerequisites

  • One clean Linux host with virtualization support and internet access.
  • Repository access and sudo privileges for installation and service checks.
  • At least one network bridge for VM connectivity on the host.
  • One endpoint machine and one USB stick for endpoint media tests.

Step 1: Install host services

Install from the repository and finish with health checks. Do not move to VM creation while required checks are red.

git clone https://github.com/meinzeug/beagle-os.git
cd beagle-os
scripts/install-beagle-host.sh
scripts/check-beagle-host.sh

Expected outcome: WebUI reachable, control plane healthy, libvirt healthy, download metadata present, no failed required checks.

Step 2: Open the WebUI and validate baseline

  1. Login to the WebUI on the host.
  2. Open health and verify host readiness.
  3. Check update channel and installed version metadata.
  4. Confirm host storage and network bridge availability.

Step 3: Create and validate one VM

  1. Create one Ubuntu Beagle VM from the WebUI.
  2. Wait for provisioning to complete and verify guest agent state.
  3. Run start, stop, restart and delete readiness checks on that VM.
  4. Record VM lifecycle evidence in the audit/event views.

If provisioning fails, inspect VM event logs and host logs before retrying. Reproducible fixes must be committed in the repository before considered done.

Step 4: Generate endpoint media

Use VM-specific download actions in the WebUI so the endpoint is pre-bound to the right target and enrollment profile.

  • Generate Linux USB writer script.
  • Generate Windows USB writer script when needed.
  • Keep checksums and metadata with your validation notes.

Step 5: Boot endpoint and verify stream

  1. Boot endpoint from generated medium.
  2. Verify endpoint enrollment appears in the WebUI.
  3. Verify endpoint is assigned to the expected VM.
  4. Start stream and confirm session health in Streams view.

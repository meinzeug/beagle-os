Architecture

One standalone platform, clear boundaries

Beagle OS is intentionally narrow: one host control plane, one active provider path, one endpoint runtime model and one stream workflow. This keeps operations and validation reproducible.

Architecture layers

WebUI and API

Operator surface for host health, VM lifecycle, endpoint state, stream and update actions.

Control plane

Service orchestration, provisioning logic, policy handling, audit events and artifact metadata.

Provider boundary

Provider contracts implemented by the active Beagle provider with KVM/libvirt runtime.

Endpoint runtime

Thin-client image, enrollment state, WireGuard path and stream-client startup behavior.

Active provider model

The active provider is providers/beagle. New coupling to Proxmox-specific APIs, paths or tooling is intentionally out of scope for current product development.

  • VM lifecycle operations resolve through provider contracts.
  • Host network and bridge selection are validated against provider inventory.
  • Provisioning fallbacks are implemented in repository code and covered by tests.

Core runtime flows

VM lifecycle

Create VM, apply image and provisioning profile, verify agent readiness, expose lifecycle controls in WebUI and API.

Endpoint lifecycle

Generate VM-specific media, boot endpoint, enroll with scoped identity, maintain heartbeat and assignment state.

Stream lifecycle

Validate guest stream services, establish endpoint path, track allocation and stream health in operational views.

State and evidence

  • Audit events capture high-impact operations: VM create/delete, stream actions, backup and policy updates.
  • Health checks summarize host readiness and deployment risk.
  • Validation artifacts are required for release promotion, especially clean-install evidence.

Design principles

  • Reproducibility over hotfix-only behavior.
  • Explicit configuration and versioned artifacts over hidden defaults.
  • Minimal exposed network surface with tunneled endpoint operations.
  • Incremental changes with test coverage and policy-aligned review.

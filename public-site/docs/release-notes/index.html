Beagle OS 8.x release line

The current product line is the standalone Beagle host: Debian 13 server installimage, KVM/libvirt provider, Beagle Web Console, VM provisioning, thin-client media, BeagleStream runtime and reproducible public artifacts.

Current status

`v8.3.9` was published as the latest stable artifact set, but fresh VM provisioning exposed a regression in the Ubuntu autoinstall media path. The repository fix is on `main` as `f05e4b7 Fix Ubuntu autoinstall media permissions`. A new release built from that commit or newer is required before the fixed server image can be treated as the clean-install baseline.

8.3.x highlights

Standalone Beagle host

Beagle OS now targets its own KVM/libvirt platform instead of a Proxmox-backed product variant.

Web Console as operator surface

The WebUI covers health, VMs, endpoints, streams, updates, downloads, backups, audit and settings.

Server installimage path

Hetzner-style Debian 13 installimage artifacts bootstrap Beagle host services after the first reboot.

Ubuntu Beagle provisioning

The VM flow builds autoinstall boot media, seed media and Beagle firstboot state for desktop VMs.

BeagleStream integration

Stream server/client integration, endpoint enrollment, WireGuard state and stream health are moving into the product path.

Known release rule

Public stable artifacts must only be promoted after a clean host install, WebUI login, host health check, VM create/delete lifecycle and first stream path have been validated from the published artifacts. Rolling host updates are useful for live verification, but they do not prove a stable installimage.

# Bugfixing

## Ablauf

1. Reproduktion sicherstellen (Test, Log, klarer Fehlerpfad).
2. Root Cause in betroffenen Services/Skripten identifizieren.
3. Kleinsten wirksamen Fix implementieren.
4. Regressionstest oder mindestens reproduzierbaren Smoke ergaenzen.
5. PR mit klarer Fehlerbeschreibung und Verifikation erstellen.

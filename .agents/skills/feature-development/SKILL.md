# Feature Development

## Ablauf

1. Lies `.agents/repo-analysis.md`, `.agents/roadmap.md`, `.agents/status.md`.
2. Waehle ein kleines oder mittleres Feature mit klarem Nutzen.
3. Leite Scope aus bestehender Architektur ab, keine Big-Bang-Aenderung.
4. Erstelle Branch und implementiere inkrementell.
5. Ergaenze passende Tests.
6. Aktualisiere Doku/Runbook bei Verhaltensaenderungen.
7. Erstelle PR, pruefe nach `.agents/review-policy.md`.
8. Merge nach `.agents/merge-policy.md`.
